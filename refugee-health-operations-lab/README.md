# Refugee Health Program Operations & Compliance Lab

Independent portfolio simulation by Michael Farzinpour, PhD (October 2026).

## Open locally
Double-click `index.html` in a modern browser. No build tools, packages, server, or internet access required for the exercises. External policy source links require internet access.

## Deploy on GitHub Pages
1. Use the existing GitHub Pages repository `michaelfarzinpour-droid.github.io`.
2. The interactive `index.html`, README, and management brief are located in `/refugee-health-operations-lab/`. The PDF version remains available in the chat download.
3. The existing GitHub Pages site deploys from the main branch.
4. The published address should follow `https://michaelfarzinpour-droid.github.io/refugee-health-operations-lab/` once GitHub Pages deployment succeeds.

## Modules
Overview dashboard; eligibility documentation verification; medical claims exception review; fiscal/invoice reconciliation; federal/state source reconciliation; dynamic management briefing; methods and reference links.

## Important boundary
All records and numerical examples are fictional. The website does **not** adjudicate actual eligibility, authorize claims payments, interpret binding legal rules, or represent any affiliation with public agencies. Federal and California program materials may differ during implementation transitions; seek current approved state guidance for operational determinations.

## Exports
In the app: download illustrative exception queue CSV; evaluate decisions to populate management decision log; print the management brief as PDF or download it as editable text. A prewritten PDF brief (`management_brief.pdf`) is also provided.

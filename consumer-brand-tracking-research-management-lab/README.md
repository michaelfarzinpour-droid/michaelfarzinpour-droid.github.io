# Consumer Brand Tracking & Research Management Lab

An interactive, static, deployable independent portfolio simulation for a fictional consumer technology client, Northstar Mobile. No NIQ affiliation is represented. All survey respondents, brands, vendors, budgets, data and results are fictional/synthetic.

## Run locally
Open `index.html` in a browser. No installation, external libraries, APIs, backend, personal information or build tooling needed.

## Publish with GitHub Pages
Create a repository called `consumer-brand-tracking-research-management-lab`, upload `index.html`, `styles.css`, `app.js` at the repository root, then open Settings → Pages → Deploy from a branch → `main` → `/ (root)`. It will be served at `https://michaelfarzinpour-droid.github.io/consumer-brand-tracking-research-management-lab/` **after** you publish the repository. This link is not active merely because you downloaded this ZIP.

## Features
- Four-wave tracking dashboard, five brand metrics, competitor and subgroup drilldowns
- Transparent deterministic 2,400-row fictional dataset (600 per wave)
- Questionnaire modules, quotas, cross-sectional poststratification weights, QA checkpoints
- SPSS-style crosstabs with independent-samples approximations and explicit limitations
- Source monitoring and choose-your-response escalation
- Concurrent workstreams, milestones, owner/dependency mapping, fictional budget and vendors
- Human versus simulated AI text-coding validation
- Analyst/client/executive navigation modes
- Seven-slide printer-friendly final presentation and executive brief
- Downloadable CSV for respondent data, questionnaire, crosstab and codes

## Statistical limitations
The synthetic data were generated by a seeded pseudorandom algorithm; are not sampled from a real consumer population; and are not an empirical brand-health report. The 95% Wald intervals and z tests are demonstration calculations and do not incorporate design effects, effective sample size or multiple-comparison corrections. Use survey-aware procedures for actual fielded work. `AI` coding proposals are fabricated deterministic labels, not model API outputs.

## Security & portability
No tracking, remote assets, cookies or external scripts. Files can be hosted on a static server. The app only creates browser-local download blobs.

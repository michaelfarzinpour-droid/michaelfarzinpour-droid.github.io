# Community Health Outcomes & Evaluation Leadership Lab — Version 2.0

An **independent, fully fictional portfolio simulation** by Michael Farzinpour (2026). It is not created by, affiliated with, endorsed by, or based on non-public data from National Health Foundation (NHF). All 720 guest episodes, four site names, outcomes, workstreams, hypothetical budgets and staffing constraints are synthetic. The fictional Housing Path Score proxy **is not** NHF's actual instrument.

## Open and publish

Open `index.html` in a modern browser. It is self-contained: no server, external JS or real patient data are required. For GitHub Pages, copy `index.html` and the documentation into a repository directory such as `/community-health-outcomes-lab/`, then enable Pages. The generated CSV may be offered as a separate downloadable reproducibility file.

## Eight modules

1. **Executive dashboard** — filter 720 records by four fictional sites, quarter and baseline-complexity level. Review housing outcomes, HPS proxy changes and completeness.
2. **Evaluation framework** — outcome definitions, denominators, validity risks and a program logic model.
3. **Data quality** — exception overview, governance choice, record-level missing-score triage and downloadable action log; does not overwrite source observations.
4. **Director simulator** — six fictional leadership scenarios with qualitative trade-off feedback; completion scores are instructional only.
5. **CEO briefing** — printable, downloadable briefing built from selected dashboard scope, simulator selections and allocation choices.
6. **Methods and sources** — dataset transparency, limitations and public background.
7. **Advanced analysis studio** — observed rates, 95% Wilson score intervals, raw risk differences, pooled-complexity direct standardization, and missing-score sensitivity assumptions. Contrast results are **descriptive and noncausal**.
8. **Organization strategy** — resource-allocation sliders, annual budget options, staffing FTE and feasibility assumptions, cross-program indicator matrix, governance responsibilities, annual calendar and downloadable strategy memo.

## Data files

- `synthetic_guest_records.csv` — 720 fictional guest records, reproducibly generated by `build.py` using seed 20261115.
- `methods_and_data_dictionary.md` — variable definitions, construction rules, analysis assumptions and limitations.
- `index.html` — all UI logic and data embedded for no-server operation.
- `template_v2.html` — authoring template with `__ROWS__` placeholder; the HTML in `index.html` is the deliverable.

## Scope and ethics

- The synthetic dataset contains no real NHF client, patient or employee information.
- Longer stays, housing navigation and positive outcomes can be associated due to deliberately constructed case mix; those contrasts **must not** be described as causal.
- Resource estimates are illustrative planning inputs, **not** forecasts of health outcomes or statements about NHF's actual budget or staffing.
- Real implementation would require operational approval, community co-design, privacy/security governance, instrument validation and IRB or compliance consultation when applicable.

EV Marketplace Analytics

5,015 simulated used-EV listings · Excel · Tableau · SQL · Python

This case study builds a weekly marketplace-health workflow for pricing, inventory, sell-through, model mix, dealer operations, battery health, and days on market. The dataset is synthetic; it is not actual marketplace, customer, or transaction data.

How the workflow works

An Excel dashboard and Tableau workbook present the recurring views. BigQuery Standard SQL queries create weekly KPIs and drill into model, inventory source, and dealer type. A Python script compares the latest week with the prior week and drafts an AI-assisted summary that distinguishes measured changes from hypotheses.

What the example suggests

In the simulated scenario, price declines across several high-volume models alongside rising inventory would prompt a market-level pricing and inventory review, rather than a response to one model. This is an illustrative result from generated data, not a real market finding.

Data boundary
All 5,015 listings and all reported movements are simulated. The project demonstrates an analytical workflow and decision framing; it does not establish an actual EV-market trend.

Consumer Complaint Analysis | CFPB Public Data

9,634 credit-reporting complaints · Rule-based issue-label taxonomy

This analysis uses a complete one-day extract of published CFPB complaint records received September 3, 2024 for the credit-reporting product. Eight consumer-selected issue labels were mapped into six themes, preserving original labels for audit.

The largest theme can inform an accuracy-resolution diagnostic and a proposed cross-functional pilot. Reported categories do not establish root causes, customer satisfaction, or confirmed resolution. The single-day snapshot is not representative of all customers or dates; no open-text, sentiment, or AI theming was performed.

Proposed next step
Review dispute evidence requests and handoffs with Insights and Operations; define a permitted process change and success threshold with Product, Service, and Compliance; then test and monitor outcomes using operational data. No intervention or customer improvement is claimed.

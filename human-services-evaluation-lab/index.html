01 / Evaluation design

Frame a question that a program team can actually use.

Scenario. A fictional California youth and family navigation initiative operates at six sites. Leaders want to know which service barriers deserve attention before deciding whether and how to improve the program. This is a training exercise, not a measured effect on real families.

Proposed evaluation questions

  1. How do service completion and follow-up response patterns differ by site, group, and barriers?
  2. What operational challenges do fictional participants describe?
  3. Which changes are feasible and worth piloting with stakeholder input?

Descriptive evaluation only. No randomized assignment or defensible causal treatment-effect estimate.

95% uncertainty intervals

Unadjusted Wilson binomial intervals for the selected outcome. The bars and this table use the current site/group filters. Intervals quantify sampling uncertainty under simplifying assumptions and do not remove selection or confounding.

Nonresponse and baseline diagnostics

Follow-up availability is not the same as improvement. Descriptive subgroup comparisons should not be interpreted as adjusted effects or causal results.

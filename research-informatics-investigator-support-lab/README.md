# Research Informatics Investigator Support & Service Coordination Lab

An **independent, fictional** interactive portfolio simulation designed to illustrate transferable research program analyst skills in investigator intake, requirements documentation, fit-for-purpose service routing, regulated-data escalation, project continuity, and research support program metrics.

**Not affiliated with or endorsed by UCLA Health or the University of California.** This website contains no real patient data or live institutional service metrics, does not access health systems, and cannot grant IRB, privacy, security, or data-owner approval.

## Run / publish

Open `index.html` in a modern browser. For GitHub Pages, upload all contents of this folder to a repository (or a `/docs` publishing folder) and enable Pages under repository Settings → Pages. The application is static and requires no build, network, backend, dependencies, or credentials. Keep the `work-products` folder alongside `index.html` so download links work.

## What is included
- Four case scenarios and 12 documented decisions with educational explanations.
- An exportable session debrief, without persistent storage.
- A dynamic dashboard with a deterministic synthetic 60-ticket dataset and CSV export.
- Six downloadable example artifacts in `work-products`.
- Transparent project boundaries and public UCLA source links in the Methods tab.

## Scenario design
1. Investigator intake — distinguish counts from individual-level needs and document assumptions.
2. Service routing — coordinate data acquisition, electronic data capture, and institutional compute/secure environment consultations.
3. Compliance & handoffs — separate IRB status from data-sharing authority, clarify decision ownership and communicate status.
4. Program improvement — define KPIs, interpret small samples responsibly, and propose a limited process pilot.

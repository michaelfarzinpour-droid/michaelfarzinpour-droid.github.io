# Qualitative Coding Framework

**All included entries and illustrative paraphrases are invented.**

| Code | Inclusion rule | Exclusion rule |
|---|---|---|
| Duplicate entry | Repeatedly entering the same order/account information | General slow webpage without reentry |
| Error recovery | Difficulty understanding or resolving a digital error | Successful self-service recovery |
| Visibility gap | Uncertainty about shipment or request status | Only actual late arrival without status concerns |
| Exception alerts | Need for proactive notice of an exception | General desire for routine notification |
| Handoff friction | Repeating information across support agents/teams | A single unresolved first contact without handoff |
| Resolution opacity | Unknown status of return/credit or case | Disagreement with the ultimate resolution |

Coding workflow: Independent double-coding on a pilot subset, disagreement log, revised definitions, audit trail, memoing of contradictory cases, and segment-level contextualization. No inter-rater reliability is claimed for this simulated material.

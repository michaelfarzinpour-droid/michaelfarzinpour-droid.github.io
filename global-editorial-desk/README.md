# Global Editorial Desk 2.0 — Independent International Communications Lab

A **fictional, independent, browser-only editorial simulation** illustrating senior university communications workflows. The simulated institution, people, quotes, events, permissions and authorizations are invented; this project is **not affiliated with UCLA** and does not represent UCLA employment, actual media outreach, actual university publishing or actual interviews.

## Run locally

Download the project folder / ZIP, extract it, and open `index.html` in a modern web browser. Keep `app.js` and `sample-data.js` next to `index.html`. No server or dependencies are required. Alternatively, upload these files into a GitHub repository and enable GitHub Pages.

## What's included

- Seven interactive editorial modules: discovery; writing and revision; strategic planning; targeted media relations; mock CMS and image editing; production calendar; executive judgment.
- Six original fictional editable work samples in `samples/`: an 835-word faculty research feature, press release, campaign brief, media kit, event recap, and newsletter/annual-report package.
- Local decision and audit trail, individual draft exports, complete-session JSON export, and an all-samples text export.
- Functional image cropping and resizing: provide your own appropriately licensed JPEG/PNG/WebP, choose aspect ratio and output width, and export a transformed PNG. User-entered credits, permissions and alt text are mandatory for export, but the app cannot independently verify image rights.
- A mock CMS with enforced draft → review → approved → published states. The approved and published states exist **only inside the browser**, not in any real institutional platform.

## Limitations and accurate representation

- No real institutional data, interviews, event attendance, outside network calls, fundraising results, donor relationship, media outreach or actual publication.
- Structural writing checks test simple text features, not factual truth. All research and quote details in writing samples are invented.
- The checklist reflects user declarations for a hypothetical scenario; it is not evidence of supervisor or university approval.
- Changes are held in memory until a page reload. Export the session to retain a record. JSON export does **not** include original image binary data; the image crop is separately exported to PNG.
- The image studio uses a center crop and does not include rotation, retouching, selective exposure correction or a full Photoshop replacement.
- Materials are personal portfolio demonstrations; not an employer work product.

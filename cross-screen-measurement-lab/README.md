# Cross-Screen Advertising Measurement & Client Insights Lab — Enhanced v2

Independent research portfolio work sample (2026).

**All data, campaigns, publishers and measurement outputs are fictional and synthetic.** This educational lab is not affiliated with Samba, uses no proprietary advertising data, and does not establish actual advertising effectiveness.

## Live application
Open [the interactive lab](https://michaelfarzinpour-droid.github.io/cross-screen-measurement-lab/). It runs in the browser with embedded CSS and JavaScript and requires no login, API, or backend.

## Features
- Three fictional publisher accounts, each with 5,000 synthetic households.
- Interactive channel selection and deduplicated household reach, impressions, average frequency and audience overlap.
- Descriptive observational exposure/tune-in comparisons, explicitly **not causal lift**.
- A separate, fixed-seed synthetic randomized holdout example reporting intention-to-treat rate differences, confidence intervals and baseline balance diagnostics. The experimental demonstration is not connected to the observational cases.
- Entertainment examples covering synthetic streaming tune-in, theatrical ticket-purchase outcomes and live-event viewing.
- Account briefs with simulated objectives, stakeholder questions, deliverables, timelines and escalation decisions.
- A quality-assurance exercise with intentionally faulty records and simulated quarantine/reconciliation workflow.
- Client-ready evidence summaries and browser-based readout export.

## Important measurement caveats
The reported experimental ITT is the difference between outcome rates by randomized assignment, not an observed real-world ad lift. The 95% intervals are unadjusted normal approximations; no statistical power or multiplicity adjustment is asserted. Fictional ticket-price scenarios are not actual box-office receipts or attributable revenue.

## Files
- `index.html` — standalone interactive web application.
- `northstar_validation_metrics.csv` — synthetic observational reference metrics.
- `randomized_experiment_validation.csv` — synthetic experimental reference metrics.

The separately prepared PowerPoint readout and reproducibility script are available in the original project package, but are not hosted in this GitHub Pages folder.

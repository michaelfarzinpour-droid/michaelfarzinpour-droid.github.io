Transparency and scope

Methods, limitations, and portfolio attribution

Creator: Michael Farzinpour, PhD, MCM, MA. Independent portfolio demonstration, 2026.

Data provenance

The fictional student case (2,400 records, six fictional colleges, 64% and 76% subgroup persistence rates) is an illustrative narrative dataset, not a real empirical result. Campaign metrics are deterministic synthetic values created for demonstration. They are not actual outreach results, and their magnitude does not validate any campaign.

Analytic boundary

The simulated comparison does not adjust for confounding, quantify causal impact, establish statistically significant differences, or identify interventions that improve persistence. It is intentionally used to demonstrate responsible wording and audience adaptation.

Professional-experience boundary

Campaign leadership, review steps, stakeholders, and evaluation choices are fictional exercises, not paid client experience, implementation at AIR, or work completed on behalf of a school or college. No individual student data, personally identifiable information, or operational agency data are used.

Accessibility features

Semantic navigation, descriptive form labels, keyboard-operable controls, live feedback announcements, visible focus indicators, high-contrast text, and responsive layouts. This demonstration has not undergone a formal WCAG conformance audit or assistive-technology testing.

Design rationale

The project prioritizes claim fidelity, audience relevance, structured review, measurable objectives, and explicit separation between communication outputs and downstream policy effects. It avoids equating reach or downloads with adoption, learning, or changes in student outcomes.

Deployment

Host this single file as index.html on GitHub Pages. It requires no server, login, build step, external fonts, third-party libraries, or network calls. Changes remain in browser memory for the current session; use exports to retain work.

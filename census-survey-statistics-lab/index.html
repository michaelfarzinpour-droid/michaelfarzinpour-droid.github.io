Weighted vs. unweighted estimation

The fictional sample intentionally overrepresents higher-education respondents in one group. The illustrative weights compensate for unequal selection patterns; these are not Census PUMS weights.

Weight adjustment depends on the correctness of selection and response assumptions. Differences do not prove either estimator is unbiased.

Sampling uncertainty demonstration

For classroom illustration only, this module uses a simplified normal approximation. It does not produce an ACS design-based confidence interval; official inference requires the ACS replicate weights and Census-prescribed variance formula.

Formula: SE = √[p(1−p)/n]; 90% interval = p ± 1.645 SE. No design effect, nonresponse adjustment, or complex survey design incorporated.

Genuine ACS PUMS verification workflow

Status: not yet completed. The project includes an offline workflow for reading official ACS person-PUMS files, using person weights and 80 replicate weights to estimate educational attainment and design-based uncertainty. The actual official-data run was blocked by download restrictions during development.

  1. Download a single-year, state-level ACS person PUMS file from the Census Bureau.
  2. Inspect variable availability, metadata, state/year, and record count.
  3. Compute the point estimate using PWGTP.
  4. Recompute it for each of PWGTP1 through PWGTP80.
  5. Calculate replicate-weight variance with the applicable ACS factor, and compare with published benchmarks where definitions align.
  6. Retain source URL, retrieval date, program version, outputs, and a reconciliation log.

Methodological notes

The synthetic demonstration is a deterministic teaching device with fictional groups and illustrative weights. Normal-approximation intervals are for simple-random-sample pedagogy only. ACS PUMS calculations require choosing the correct universe, using the provided person or housing weights, 80 replicate weights, and the applicable Census replicate-weight variance formula. Subgroup differences should be computed through replicate-level contrasts to retain covariance.

No private respondent information is used. No Census agency affiliation is claimed. Neither the simulated estimates nor any user-imported JSON are represented as officially verified Census statistics.

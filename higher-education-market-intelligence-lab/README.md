# Higher Education Market Intelligence & Program Strategy Lab — Version 2

**Created November 12, 2026 | Independent work sample | No SNHU or peer-institution affiliation or endorsement.**

## Start here
Open `index.html` in any recent browser. It is self-contained and works offline. The five sections cover observed market signals, qualitative competitive intelligence, hypothetical decision scoring, quality controls/source register, and a print/copy-ready executive brief.

## What's genuinely real in V2
- **2021–22 U.S. and Arizona awards:** exact NCES Digest 2023, table 319.30 figures in three broad bachelor's fields.
- **National 2011–12 vs 2021–22 trend endpoints:** published NCES figures; some old values are rounded.
- **Selected SNHU program-specific online graduate counts, 2021–22 through 2024–25:** from SNHU's public ACBSP report. The count is specific to covered programs and not university-wide.
- **Catalog comparison:** selected degree titles are cross-checked against official ASU Online and WGU catalogs. Presence is not a quantitative competitor market share.

## What's illustrative, not real institutional data
All proposed new degrees and five scoring dimensions, evidence thresholds, priorities and any launch/pilot/defer recommendation. An interactive score is *not* an empirical demand estimate, admissions projection, or claim about a real university's capabilities.

## Published GitHub Pages files
- `index.html` — self-contained interactive dashboard, public-data snapshots, adjustable illustrative decision scoring, and printable executive memo.
- `README.md` — scope, provenance, interpretation and caveats.

## Companion reproducibility package
The companion ZIP, provided separately with this portfolio work sample, contains the full CSV source register, Python analysis and integrity tests, methodological notes, Power BI example code, and editable leadership presentation. Those supplementary assets are **not included in this GitHub Pages directory** and should not be represented as a deployed Power BI report or live IPEDS data pipeline.

The published dashboard embeds a static research snapshot. It does not automatically retrieve fresh institutional data or replace manual source verification.

## Source limitations
IPEDS released newer provisional data than this limited field-level published extract. The demo uses documented historical reference years, not the latest complete institution-level data. See `docs/METHODOLOGY.md` before citing numerical results.

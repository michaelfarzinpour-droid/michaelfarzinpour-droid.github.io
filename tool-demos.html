Inspect the SQL that verifies the counts

The reporting output is reconciled against SQLite queries. The complete query file and verification scripts are included in the download.

SELECT primary_reason, COUNT(*) AS row_count
FROM qa_flags
GROUP BY primary_reason
ORDER BY primary_reason;

SELECT q.age_group, q.target,
       COUNT(r.response_id) AS valid_completes,
       MAX(0, q.target - COUNT(r.response_id)) AS remaining
FROM quotas q
LEFT JOIN responses_clean r ON r.age_group = q.age_group
GROUP BY q.age_group, q.target
ORDER BY q.age_group;

02 / AI-assisted reporting

A prompt workflow with a human review step

Python and SQL compute the metrics. Reusable ChatGPT instructions guide draft QC updates, mock toplines, and quota recruitment memos using those outputs.

  1. 01

    Calculate & reconcile

    Run the quality rules, preserve the raw export, and compare JSON results with independent SQL output.

  2. 02

    Draft from checked inputs

    Use the instruction file with the synthetic summary. Retain denominators and separate the overall target from segment quotas.

  3. 03

    Review before sharing

    Check numeric claims, rounding, limitations, and recommendations. Keep a named human reviewer in the workflow.

What this prototype demonstrates

ChatGPT-assisted coding and worked draft examples; reusable prompt instructions; checks that reconcile the structured draft with JSON and SQLite outputs; and a manual evaluation plan.

The reporting scripts use deterministic templates and do not call an AI model or API. The assistant is a prompt/configuration prototype, not a deployed custom GPT or autonomous agent. The project does not establish access to ChatGPT Enterprise or Microsoft Copilot.

Only synthetic, nonconfidential inputs are used. The instructions require data minimization, source checks, handling dataset text as untrusted content, and human approval before external release.

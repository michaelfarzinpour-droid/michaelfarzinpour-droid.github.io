# Michael Farzinpour — Audience and Marketplace Insights

A static portfolio focused on a public-data case study of five selected June 2025 film releases. It compares each film’s first four domestic box office weekends and includes reported viewing snapshots for two official YouTube trailers.

The homepage opens directly to the film case study. Downloadable materials include an Excel dashboard, a short PowerPoint deck, source records, and reproducible Python and SQL analysis. The two trailer counts are October 2026 snapshots and do not establish historical demand, audience fit, or campaign reach.

## Publishing

Publish the main branch from the repository root in GitHub Pages settings. The root contains index.html and .nojekyll; no build step is required. Asset and download links use relative paths, so the portfolio works on either an account-level Pages address or a project Pages address.
